## ⑤ 파일 구성

<!-- 어떤 파일이 무엇을 하는지 한 줄씩. -->

| 파일 | 하는 일 |
| --- | --- |
| `load_scores.py` | CSV에서 유효한 성적과 제외한 행의 기록을 반환한다. |
| `scores.csv` | 정상 파일 읽기 테스트에 사용한 성적 데이터다. |
| `empty.csv` | 헤더만 있는 CSV 파일이다. |
| `weird.csv` | 예외적인 입력을 확인하기 위한 예시 CSV 파일이다. |
| `test_load_scores.py` | `scores.csv`에서 유효한 성적이 5개 나오는지 확인한다. |
| `test_ai_A.py` | AI에게 함수 코드를 주고 받은 테스트다. |
| `test_ai_B.py` | AI에게 함수 명세를 주고 받은 테스트다. |
| `prompts.txt` | A와 B 실험에 사용한 프롬프트 원문이다. |
| `bug3_logic.py` | 최댓값을 구할 때 마지막 점수를 놓치는 버그를 살펴본 실험 파일이다. |
| `README.md` | 프로그램 실행 방법과 테스트 결과를 정리한 문서다. |
